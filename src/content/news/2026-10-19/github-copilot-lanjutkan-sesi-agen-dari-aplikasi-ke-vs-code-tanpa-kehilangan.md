GitHub (19/10) mempublikasikan panduan terbaru di blog resminya yang menjelaskan cara memindahkan sesi agen Copilot dari aplikasi GitHub Copilot ke editor Visual Studio Code. Fitur ini dirancang agar pengguna tidak kehilangan percakapan, perubahan kode, maupun konteks kerja ketika berpindah dari satu lingkungan ke lingkungan lain.

Bagi developer yang sering berpindah perangkat, kemampuan melanjutkan sesi secara mulus berarti pekerjaan yang sudah dibangun bersama agen tidak perlu diulang. Cukup membuka sesi yang sama di VS Code, riwayat obrolan dan status pekerjaan akan tampil seperti semula. GitHub menjelaskan langkah-langkah yang diperlukan, mulai dari membuka sesi di aplikasi Copilot hingga memindahkannya ke editor melalui pintasan dan perintah yang tersedia.

Secara umum, agen Copilot adalah mode asisten yang dapat menjalankan tugas secara lebih otonom, seperti menelusuri basis kode, mengusulkan perubahan, dan menjalankan perintah tertentu. Dengan adanya kelanjutan sesi antar-perangkat, alur kerja yang dimulai di aplikasi bisa diselesaikan di editor, atau sebaliknya, tanpa harus menyalin hasil secara manual.

Panduan ini menyasar pengguna yang sudah terbiasa memakai Copilot di kedua lingkungan dan ingin menjaga kontinuitas kerja. GitHub tidak menyebutkan perubahan pada paket berlangganan maupun ketersediaan fitur di wilayah tertentu dalam rilis tersebut.
