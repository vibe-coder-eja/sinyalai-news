Microsoft mengumumkan pembaruan mendasar pada arsitektur produk **Copilot** untuk menghubungkan perangkat kerja harian dengan ekosistem agen AI otonom. Pembaruan ini memperkenalkan tiga pilar utama: antarmuka personal **Copilot Home**, lingkungan rekayasa kode **Copilot Code**, serta mode otomatisasi tugas berantai **Autopilot**.

Langkah ini dirancang untuk mengubah peran asisten AI dari sekadar alat tanya-jawab pasif (*conversational UI*) menjadi mitra kerja proaktif yang mampu mengeksekusi proses bisnis multi-langkah.

## Tiga Fitur Utama Copilot Baru

- **Copilot Home**: Dasbor terpadu yang merangkum konteks kerja lintas Microsoft 365 (Teams, Outlook, SharePoint, OneDrive), menyajikan rekomendasi prioritas harian, dan melacak status pengerjaan dokumen.
- **Copilot Code**: Fitur pemrograman cerdas yang tidak hanya melengkapi baris kode (*autocomplete*), tetapi dapat menguji, mendokumentasikan, dan mengajukan pull request perbaikan bug secara mandiri di VS Code dan GitHub.
- **Mode Autopilot**: Memungkinkan pengguna mendelegasikan tugas administratif panjang—seperti sintesis transkrip rapat, tindak lanjut email vendor, dan pembaruan data spreadsheet—dengan kontrol perizinan berjenjang (*human-in-the-loop*).

## Menuju Era Agen di Tempat Kerja

Transformasi Copilot ini mencerminkan pergeseran besar di industri enterprise software. Integrasi mendalam antara model frontier dan data internal organisasi kini menjadi arena pertempuran utama bagi penyedia platform produktivitas digital.
