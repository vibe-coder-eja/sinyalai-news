Anthropic mengumumkan tiga pembaruan utama untuk lini model Claude 3.5, meliputi kemampuan computer use, model Claude 3.5 Sonnet versi terbaru, serta model Claude 3.5 Haiku. Fitur computer use memungkinkan Claude untuk berinteraksi langsung dengan antarmuka komputer, seperti menavigasi layar, menggerakkan kursor, dan mengetik, sehingga agen AI dapat menjalankan tugas pada aplikasi dan software yang tidak memiliki API khusus.

Secara teknis, computer use bekerja dengan cara Claude menganalisis tangkapan layar (screenshot) dari lingkungan desktop atau browser, lalu menghasilkan aksi berupa perintah klik, input teks, atau navigasi menu. Kemampuan ini tersedia dalam versi beta publik melalui API, SDK, dan playground milik Anthropic. Sementara itu, Claude 3.5 Sonnet versi baru diklaim mengalami peningkatan performa pada benchmark pengkodean (coding) dan penggunaan alat (tool use), dengan harga dan kecepatan yang sama seperti versi sebelumnya. Claude 3.5 Haiku juga diperbarui dengan peningkatan kemampuan penalaran dan respons yang lebih cepat.

Untuk ketersediaan, Claude 3.5 Sonnet versi terbaru sudah dapat diakses oleh semua pengguna melalui API, Amazon Bedrock, dan Google Cloud Vertex AI. Fitur computer use tersedia dalam tahap beta publik bagi para pengembang untuk diuji coba. Claude 3.5 Haiku akan dirilis dalam beberapa minggu ke depan melalui API dan platform cloud tersebut.
