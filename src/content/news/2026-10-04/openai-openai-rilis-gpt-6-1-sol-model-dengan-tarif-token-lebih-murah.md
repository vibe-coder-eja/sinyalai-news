OpenAI resmi memperkenalkan GPT-6.1 Sol, model bahasa terbaru yang dirancang untuk aktivitas coding, computer use, dan pekerjaan profesional. Model ini digadang memiliki tingkat kecerdasan mendekati lini Astra milik OpenAI, tetapi dipasarkan dengan struktur harga yang lebih rendah untuk penggunaan API.

Secara teknis, GPT-6.1 Sol diposisikan sebagai model kelas menengah-atas yang menyasar beban kerja teknis seperti pembuatan kode, otomasi antarmuka komputer, serta pemrosesan dokumen profesional. OpenAI mengklaim kemampuan penalaran dan eksekusi tugas model ini mendekati performa Astra, lini model andalan mereka, sehingga pengguna dapat menjalankan alur kerja kompleks tanpa harus beralih ke model dengan harga premium.

Dari sisi harga, GPT-6.1 Sol ditawarkan dengan tarif input dan output token sebesar seperlima dari harga standar API Astra. Penurunan tarif ini membuat model lebih mudah diakses oleh developer, startup, dan tim teknis yang sebelumnya terkendala biaya penggunaan API kelas atas. OpenAI menyediakan akses melalui API dan platform ChatGPT, lengkap dengan dokumentasi teknis serta panduan integrasi bagi pengguna yang ingin mengadopsi model ini untuk kebutuhan produksi.
